# Yanlış Cevap Hesap Makinesi

## Dünyanın En Yanlış Cevap Veren Hesap Makinesi

Bu proje, insanlığın doğru cevap vermekten vazgeçtiği o kutsal anı simgelemektedir. Artık 2+2=4 demek yasaktır. Anayasa Mahkemesi kararıyla doğru cevap vermek anayasal suç kapsamına alınmıştır. Bu hesap makinesi, o yasağa saygı duyar ve asla doğru cevap vermez.

### Özellikler
- Toplama işlemi yapar ama yanlış yapar.
- Çıkarma işlemi yapar ama yanlış yapar.
- Çarpma işlemi yapar ama yanlış yapar.
- Bölme işlemi yapar ama yanlış yapar.
- Bazen hiç sayı vermez, "Hayır" der.
- Bazen 42 der, çünkü hayatın anlamı odur ama yanlıştır.

### Kullanım
```bash
python calculator.py
```

Sonra size sorulan sayıları girin ve yanlış cevapların keyfini çıkarın.

### Uyarı
Bu programı kullanmak sizi doğru cevaplardan kurtarır. Matematik öğretmeniniz üzülebilir. Sorumluluk kabul etmiyoruz.

### Gizli Bölüm
Aslında her şey bir yanılsama. Doğru cevaplar sadece birer sosyal yapılandırma. Gerçek özgürlük yanlış cevap vermekte yatar.
